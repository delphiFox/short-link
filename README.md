# Приложение позволяет сократить URL, получить уникальную короткую ссылку и управлять её параметрами

## Основные функции:
- [x] На основании URL создает уникальную короткую ссылку
- [x] Позволяет перейти на оригинальную ссылку ограниченное количество раз
- [x] Одному пользователю (UUID) может принадлежать множество ссылок
- [x] Ссылки, время жизни которых истекло, автоматически удаляются 
- [x] Параметры конфигурации приложения в отдельном файле config/param.txt
- [x] Взаимодействие с приложением выполняется через CLI
- [ ] **Замечание**! Каждая отдельная операция оканчивается завершением работы приложения.
При этом состояние между перезапусками сохраняется.
Подобная реализация оставлена, поскольку требования такое поведение не запрещают.

## Стек:
- [x] JDK 21
- [x] локально подключены библиотеки org.json и junit (отдельной установки не требуют)

## Описание работы с примерами команд
### 1. Создание коротких ссылок
Новый пользователь вводит URL, после чего пользователю присваивается UUID, создается сокращенная ссылка и максимальное число переходов по умолчанию - 4 (значение получается из файла конфигурации).
Новый пользователь также может ввести URL с указанием лимита числа переходов - в этом случае система примет лимит, указанный пользователем.
Вводимые данные валидируются.

### 2. Переход (редирект) по ссылке
Перейти возможно только по ссылке, принадлежащей пользователю.
При вводе UUID система отображает все ссылки, принадлежащие пользователю, и предлагает ввести ссылку для перехода.
При вводе короткой ссылки выполняется переход в браузере на указанный URL.
Наличие ссылки проверяется.

### 3. Лимит переходов
При достижении лимита переходов по ссылке возникает сообщение о достижении предельного лимита
Лимит может быть задан пользователем при создании ссылки или берется значение, заданное в файле конфигурации.
> Ссылка при этом не удаляется

### 4. Многопользовательский режим
Каждая новая введенная ссылка для сокращения порождает создание нового пользователя (UUID) - таким образом осуществляется многопользовательский режим.
Каждый пользователь, в свою очередь, может иметь неограниченное количество ссылок.
> Лимит переходов устанавливается отдельно на каждую ссылку

### 5. UUID-идентификация и правка
При вводе UUID, который ранее создавал ссылку, система отображает все ссылки, принадлежащие текущему пользователю, и предлагает ввести кодированное значение короткой ссылки, данные которой предполагается изменить.
После ввода кодированного значения, предлагаются следующие изменения:
- указание нового наименования длинной ссылки
- изменение лимита переходов
- удаление ссылки
> При изменении ссылки дата её создания не меняется, т. е. ссылка будет удалена по истечении времени жизни от момента её создания

### 6. Время жизни и автоудаление
В конфигурационном файле указывается число в минутах (параметр **limit_lifetime_minute**), с которым ежеминутно сверяются все имеющиеся в системе ссылки.
По достижении интервала времени с момента создания ссылки до истечения количества минут (**limit_lifetime_minute**) ссылка удаляется.

### 7. Уведомления
В консоли отображаются следующие уведомления:
- Для ссылки _xxx_ достигнут предельный лимит переходов
- У пользователя _xxx_ удалена ссылка _xxx_ по истечении времени жизни

### 8. Конфигурация приложения
Из отдельного конфигурационного файла **config/param.txt** при старте приложения получаются следующие параметры:
- префикс (**link_prefix**): часть короткой ссылки до символа "/"
- длина кодированного значения (**link_length**): часть короткой ссылки после символа "/"
- лимит переходов по короткой ссылке (**limit_restriction**): значение принимается, если пользователь его не указал при создании ссылки
- время жизни ссылки (**limit_lifetime_minute**): срок в минутах, по достижении которого ссылка удаляется
> После удаления ссылки пользователь, которому ссылка принадлежит, по-прежнему остаётся в системе

### 9. Обработка ошибок
Все данные, вводимые пользователем, валидируются на предмет их корректности и соответствия внутреннему состоянию.
Например, у одного пользователя длинные ссылки могут быть только уникальными.
Кроме того, пользователь не может удалить или изменить не принадлежащую ему ссылку.
Все ошибки валидации отображаются.
